// 页面只要引一行，离线可用（相对路径按所在目录调整） <script src="../../assets/sfx/sfx.js"></script> RTSXSFX.play("click"); // 同类随机挑一个 RTSXSFX.play("score", { volume: .85 }); RTSXSFX.setPreference("click", "ui-click-2.wav"); // 固定选择，会记住 RTSXSFX.setPreference("click", null); // 恢复随机 /* 想要"某个按钮固定某音效"： */ <button data-sfx="start">开始</button>
音效全部由 tools/gen-sfx.js 程序合成后写成 16-bit PCM WAV，没有外部素材、没有版权问题；重新生成就运行 node gen-sfx.js。清单见 manifest.json。
